# 《삼국지 군웅전기》 15라운드 독립형 프로토타입 v1.2

이 프로젝트는 기존 《삼국지 백팩 배틀즈》 v20.1을 변경하거나 덮어쓰지 않고, 합의된 새로운 설계를 시험하기 위해 만든 **별도 게임**입니다.

## 실행

- 가장 간단한 방법: `군웅전기_15전_바로실행.html` 파일을 Chrome 또는 Edge로 열기. 인터넷 연결과 외부 서버는 필요하지 않습니다.
- 개발용 분리 파일로 실행하려면 `index.html`, `style.css`, `data.js`, `app.js`를 같은 폴더에 두고 `index.html` 열기.
- 이어하기는 동일 브라우저의 `localStorage`를 사용합니다. 브라우저 데이터 삭제 또는 브라우저/보안 설정에 따라 진행 상황이 소실될 수 있습니다. 정식 Steam 출시용 파일 저장·Steam Cloud는 아직 구현하지 않았습니다.

## 반영한 확정 기획

1. 전투 대상 선택 없이 **완전 자동 공격**. 수동 타겟팅 없음.
2. 초기 사용 가능 장수 **21종**: 촉 7(유비, 관우, 장비, 조운, 제갈량, 마초, 황충), 위 7(조조, 하후돈, 장료, 전위, 허저, 사마의, 순욱), 오 7(손권, 손책, 주유, 감녕, 태사자, 황개, 육손).
3. 기존 C~SSS **장수 등급 제거**. 기본 능력치(체력, 통솔, 무력, 지력, 정치, 원본 기본 쿨타임)는 v20.1의 `rawDB` 값을 사용하며 별도의 패시브 특성은 이번 프로토타입에 적용하지 않음.
4. 기존 9×9 배낭 제거: **보유 장수 목록과 전투 진형 분리**. 전열 4칸·후열 4칸, 기본 최대 출전 5명. 손자병법 보유 시 최대 6명.
5. 장수 최대 보유 8명. 동일 이름의 장수 중복 영입 가능. 장수별 스킬 레벨·투자·사용 기술 독립 저장.
6. **전투에서 승리하면 재야탐색 1회** 활성화. 촉·위·오 21종 중 무작위 3명이 등장하고 한 명을 선택. 보유 정원이 가득 차면 방출 후 등용하거나 등용 기회를 포기할 수 있음.
7. 스킬 4개 중 전투에 사용할 1개 지정 가능. 장수 등용 시 서로 다른 **초기 스킬 3개에 Lv.1을 무작위 배분**, 이 3포인트는 영구 고정되어 회수 불가.
8. 개별 스킬 최대 Lv.3. 장수 하나당 유료 강화 최대 4회: Lv.0→1은 2금, Lv.1→2는 4금, Lv.2→3은 8금. 비용을 감당할 수 있으면 한 번에 4회 투자 가능.
9. 유료 투자분을 취소할 때는 이전 강화 비용의 **절반을 추가 지불**하고 사용한 강화 횟수 1회를 돌려받음: Lv.3→2는 4금, Lv.2→1은 2금, Lv.1→0은 1금.
10. 장수 방출은 확인창을 거치고 해당 장수의 모든 스킬 투자 기록이 함께 소멸.
11. 촉 7명의 **고유 스킬 28개**를 합의한 이름·방향·레벨별 위력에 맞춰 실제 전투에 연결.
12. **유비 두 명이 모두 도원결의 사용 시 중첩**. 각 장수의 독립된 고유 ID를 버프 출처로 사용하므로 두 유비의 7%와 12%가 동시에 살아 있으면 아군에게 합계 19%가 적용됨. 같은 유비 자신의 반복 발동은 기존 효과의 지속시간만 갱신.
13. 전투·사건·보물·의원·상점의 3열 분기 지도 구조를 **15전 시험용으로 간략 재구성**. 1~15전 적군 이름·기본 능력치·기술은 v20.1의 적군 v15 데이터에서 추출.
14. 전투 자동 진행, 배속 ×1·×2·×3, 전투 기록·체력 표시, 출정 저장, 15전 완료 표시.

## 아직 미완성 또는 임시인 부분 (중요)

- **위·오 장수 14명의 스킬 56개는 정식 설계 전입니다.** 플레이 흐름을 시험하도록 `임시 · 공격/방어/책략/지원` 공용 4기술을 넣었습니다. 장수 21종을 등용·성장시키는 기능은 있지만 촉나라처럼 개별 역사적 기술이 완성된 것은 아닙니다.
- 촉나라 28개 스킬은 기술별 기본 쿨타임을 **시험값**으로 지정했습니다. 이번 시제품에서 쿨타임, 금화 수급, 전투 난이도는 최종 밸런스가 아닙니다.
- 기존 v20.1의 모든 적군 특성·전술·상태 효과를 그대로 이식하지 않았습니다. **적군 1~15전의 이름과 기본 데이터는 재사용**, 신작용 자동 전투 계산 로직은 별도로 단순화했습니다.
- 기존 맵의 3열 분기 및 주요 노드 분류를 유지해 **새 UI로 재구성**했으며, v20.1 맵의 정확한 노드 배치·연출과 동일하진 않습니다.
- UI는 큰 텍스트·간단한 한자 초상 자리 표시자를 사용합니다. 원래의 105명 국가별 초상화 원본 시트는 v20.1 ZIP에 들어 있지 않아 신작 ZIP에 포함하지 않았습니다.
- 아이템은 신작의 9×9 아이템 배치 대상이 아닙니다. 시험용 보물은 손자병법·청낭서·학우선·적로를 사용하고 있으며 손자병법의 효과는 사용자 확정 규칙(출전 인원 +1)에 따라 변경했습니다.
- 초기 출전 장수(진영별 3명), 시작 금화 6금, 전투 승리 금화 5금(5의 배수 전투 7금), 기술별 쿨타임, 선택형 옆길의 간단한 효과 등은 **아직 승인받지 않은 임시 테스트값**입니다. 이후 사용자와 협의해 조정해야 합니다.
- 현재는 오프라인 HTML 브라우저 프로토타입입니다. Windows EXE, Steam 배포·도전과제·Steam Cloud는 구현하지 않았습니다.

## v1.2 UI 변경 사항

- 시작 화면은 **새로하기 / 이어하기** 버튼만 표시합니다. 저장 기록이 없을 때 이어하기는 비활성화됩니다. 새로하기를 누르면 **촉 / 위 / 오** 세 진영만 선택할 수 있습니다. 시작 장수 목록은 표시하지 않습니다.
- 전투 진형에 출전 중인 장수는 보유 장수 카드 목록에서 숨겨, **대기 중인 장수만** 보여 줍니다. 우측 카운터에는 대기 인원과 총 보유 정원(출전 포함)이 표시됩니다.
- PC: **대기 장수를 드래그해 진형에 놓으면 배치**됩니다. 진형의 장수도 드래그하여 위치를 바꿀 수 있습니다. 장수 카드를 누르면 상세 팝업을 확인합니다.
- 모바일: **대기 장수 터치 → 진형 칸 터치**로 배치합니다. 대기 장수 오른쪽 위의 ⓘ 또는 배치된 장수를 터치하면 상세 팝업이 열립니다. 출전 중인 장수는 상세창에서 `위치 변경` / `대기로 이동`을 선택할 수 있습니다.
- 장수 카드에 표시되는 텍스트는 **이름뿐**입니다. 기술 레벨이나 기술명은 카드에 보이지 않고, 장수 상세 팝업에서 확인할 수 있습니다.
- 상세 팝업에는 기본 체력·통솔·무력·지력·정치와 각 스킬의 **스킬명, 데미지, 현재 효과, 스킬 쿨타임**을 표시합니다. 장수 기본 쿨타임은 UI에 표시하지 않습니다(전투 계산 내부 값은 변경하지 않았음).
- 스킬의 `데미지 0`은 직접 피해를 주지 않는 기술입니다. 공격 기술의 150% 같은 값은 기본 물리/책략 피해에 대한 **기술 피해 배율**로, 적의 방어 능력치와 상태에 따라 실제 피해량은 달라집니다.
- `스킬 강화`를 누르면 현재 Lv.와 다음 Lv.의 **데미지·효과·쿨타임**을 나란히 비교하고 **필요 금화**를 확인한 뒤 결제할 수 있습니다. 기존 유료 포인트 회수 기능도 상세 팝업에서 유지됩니다.
- 장수 등용, 스킬 성장 제한, 자동 전투, 15라운드 진행, 맵과 전투 밸런스 규칙은 v1.1에서 변경하지 않았습니다.

## 조작 방법

- `새로하기` → `촉 / 위 / 오` 선택 → 출전 진형 확인.
- PC: 대기 장수를 진형으로 드래그. 모바일: 대기 장수 터치 후 원하는 진형 칸 터치.
- 보유 장수 카드의 ⓘ 또는 전투 진형의 장수를 누르면 상세 팝업. `스킬 지정`으로 사용할 스킬 선택, `스킬 강화`에서 효과 비교 후 강화.
- `출정 지도`에서 현재 전투 시작. 전투 후 `장수 편성`으로 돌아와 `재야탐색`으로 한 명 등용.
- 필요 없는 장수는 상세 팝업의 `장수 방출`에서 확인 후 방출.

## 검증 범위

- Node.js에서 `app.js`, `data.js` 구문 검사 통과.
- Chromium의 HTML 인라인 실행 모드에서 촉나라 시작, 8칸 진형·21명 데이터, 스킬 강화·회수(예: Lv.1→3에 12금, Lv.3→2 회수에 4금), 재야탐색 등용, 보유 8명 상한, 같은 이름의 장수 독립 ID, 확인 경고 문구 검사.
- `도원결의` 중복 유비 2명의 버프 실제 합산 19% 검사.
- 1~15전 적군을 강제로 처치시켜 모든 라운드 승리 후 보상·해금·최종 종료 처리가 정상 작동하는지 검증. **실제 15전 완주 테스트가 아님.**
- 단순 자동 편성/보상 루틴을 이용한 8번의 통제된 실제 전투 시뮬레이션에서 6번 최종 15전 승리 (나머지는 12~14전 패배). **유저 승률이나 목표 난이도를 대표하지 않음.**
- Chromium에서 1280px/390px 화면 렌더링 및 JavaScript 예외 없이 기본 UI 흐름 확인. 실제 Windows 실사용·Safari·Steam 배포 테스트는 미실시.

## v1.2 확인 내용

- Chromium 데스크톱과 모바일 터치 환경에서 두 버튼 시작 메뉴, 진영 선택, 초기 출전 장수의 대기 목록 제외를 확인.
- PC 대기 장수 드래그 배치, 모바일 대기 장수 선택→진형 터치 배치, 출전 장수 상세창 및 대기로 이동 검사.
- 스킬 강화 전후 효과 표시, 금화 차감 및 상세창 갱신, 재야탐색 후 대기 장수 표시, 출정 자동 저장/이어하기 확인.
- `index.html`, `style.css`, `app.js`만 수정했고 `data.js`의 장수·적군 데이터는 v1.1과 동일. 별도 브라우저 실사용 환경(특히 Safari) 및 실제 15라운드 연속 클리어는 이 버전에서 새로 검증하지 않음.
